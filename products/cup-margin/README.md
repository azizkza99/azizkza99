## اعرف ما يتركه كل كوب

البن والحليب ليسا التكلفة كاملة. «هامش الكوب» يجمع المكونات والهدر والتغليف والعمل المتغير وعمولات البيع، ثم يحسب ما يبقى لتغطية التكاليف الثابتة.

## ما الذي تتضمنه النسخة الكاملة؟

- أداة عربية مستقلة تعمل في متصفح الكمبيوتر دون Excel أو اشتراك.
- حتى 30 مكوّناً لكل وصفة، وحفظ حتى 100 وصفة محلياً.
- حساب تكلفة العبوة والكمية المستخدمة والهدر والتغليف والعمولات.
- فصل النسبة الضريبية المدخلة عن السعر، مع اختيار أساس العمولة.
- حساب هامش المساهمة وسعر يحقق نسبة مستهدفة.
- سيناريو نقطة تعادل لمشروب واحد أو أكواب لها هامش المساهمة نفسه.
- تقرير CSV، طباعة التقرير، وتصدير/استيراد JSON للنسخ الاحتياطي.
- دليل عربي وأمثلة افتراضية وترخيص استخدام داخلي لنشاط تجاري واحد وفروعه.

## مثال توضيحي افتراضي

| البند | القيمة |
|---|---:|
| سعر العميل | 18.00 ريال |
| نسبة ضريبة افتراضية مشمولة | 15% |
| الإيراد بعد استبعادها | 15.65 ريال |
| تكلفة متغيرة، تشمل عمولة البيع | 4.14 ريال |
| هامش المساهمة | 11.51 ريال |

هذا مثال تعليمي وليس أسعار سوق. **هامش المساهمة ليس صافي الربح.**

## التشغيل والخصوصية

بعد الشراء والتنزيل، افتح `Cup-Margin.html` على الكمبيوتر. لا تحتاج مفتاح API أو اتصالاً بالإنترنت لتشغيل النسخة المحملة. بيانات الوصفات تبقى محلياً؛ احتفظ بنسخة JSON خارج المتصفح. الواجهة متجاوبة، لكن فتح ملفات HTML محلياً على الهاتف يعتمد على نظامه.
